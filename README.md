AutoLoot adds two innate toggle skills to your characters that automatically collect items from the ground, containers, and corpses within a 15-meter radius. Switch between two modes:

Auto Loot (Normal) — collects only unowned items, safe to use anywhere.
Auto Steal — collects everything, including owned property, unlocks containers, and suppresses the crime system so NPCs never react.
The mod is designed to be lightweight, configurable, and crime-safe. It requires Script Extender v56+.
Reads your character's Luck stat in real time and calls the game's treasure generator on each newly opened container. Every 5 points of Luck triggers an additional loot roll, exactly as the vanilla Lucky Charm talent does.
